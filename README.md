# Addon Latam plugin
 
Ahora también tenemos plugin para Nuvio. Contenido en Español/Latino: películas,
series, anime y donghuas de distintos sitios.

[![JavaScript](https://img.shields.io/badge/JavaScript-Runtime-black?style=for-the-badge&logo=javascript&logoColor=white&color=F7DF1E)](https://developer.mozilla.org/docs/Web/JavaScript)

- Página de Addon Latam: https://addonlatampagina.duckdns.org
- Instalar el addon de Addon Latam desde Stremio Addons: https://stremio-addons.net/addons/addon-latam


## Instalar en Nuvio

Settings → Plugins → agregar esta URL:

```
https://raw.githubusercontent.com/Droydr13/pluggin-latino/main
```

## Avisos conocidos

- **AnimeJL** y **EntrePeliculasYSeries** usan protección de Cloudflare;
  cuando el sitio pide verificación de navegador, Nuvio no puede pasarla y
  esos dos devuelven vacío hasta que el sitio deje de pedirla.
